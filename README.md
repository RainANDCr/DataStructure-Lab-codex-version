## 五分钟上手

1. 从左侧进入 **课程知识体系 · 408**，选择“大学课程”或“考研 408”，按章节阅读定义、性质、例题和常见错误。
2. 点击知识点中的**对应动画**。建议先预测下一步会发生什么，再点击“下一步”核对。
3. 在动画旁切换 **C、C++、Python** 代码，观察当前高亮行、变量和图形如何对应。
4. 点击**练习这个知识点**，或进入 **算法推演题库** 答题。提交后查看解析。
5. 到 **学习记录与复习** 查看错题和复习安排。学完一个算法，还可以点击“标记为已学习”。

想直接试一试？打开[冒泡排序实验台](https://rainandcr.github.io/DataStructure-Lab-codex-version/#/lab/bubble)，输入 `5, 2, 8, 1`，点击“应用数据”，再逐步播放。

### 以冒泡排序为例，完整走一遍

1. 在实验台输入 `5, 2, 8, 1` 并点击“应用数据”。数组图会显示四个元素及其下标。
2. 点击“下一步”，先读步骤下方的中文解释，再看高亮的元素、代码行和变量监视器。继续点击，观察相邻元素何时比较、何时交换。
3. 点击“上一步”，确认数组、计数器和变量一起回到上一个状态；再拖动步骤滑块，直接比较不同阶段。
4. 切换 C、C++、Python 标签，观察同一步对应的参考代码。需要保存这组输入时，使用“我的案例”中的“保存当前数据”。
5. 打开页面顶部的“关联知识”，理解排序稳定性，再进入题库做一道相关题，最后在“学习记录与复习”查看结果。

## 按课程或 408 学知识点

左侧的“课程知识体系 · 408”提供两种视角：

| 视角 | 如何使用 |
| --- | --- |
| 大学课程 | 按教材九章浏览，适合先建立概念、结构与操作的知识框架。 |
| 考研 408 | 按站内整理的 2027 年数据结构考查范围查找条目，适合复习时定位知识点。 |

进入页面后，先选章节，再在“知识依赖图”中点击一个节点。箭头表示先修关系。知识点详情含定义、图形解释、性质、典型例题、常见错误和前置知识；“查看答案与解释”用于课后自测。掌握概念后点“对应动画”，完成观察后再点“练习这个知识点”或“练习本章题目”。如果当前筛选没有相关题目，可回到题库放宽筛选。

“内容完整”表示该知识点已有站内讲解，不能替代教材或官方考纲。页面的 408 范围来源于用户提供文本，尚未独立核验。

## 使用算法实验台

- **找算法：**左侧按九章分类，搜索框可按算法或章节查找。还有算法对比、指针与内存模拟、递归调用栈和代码调试等专题。
- **更换输入：**按当前页面的格式提示填写数据，点击“应用数据”。不同算法的输入范围和上限可能不同。
- **控制步骤：**“播放”自动前进，再次点击可暂停；“上一步”“下一步”用于单步观察；拖动滑块可跳转，“重置”返回起点，速度菜单可调整节奏。
- **对照代码：**切换 C、C++ 或 Python 标签，观察高亮行与当前操作。代码是教学参考片段；网站不会编译或运行任意用户代码。内存地址也是教学模拟。
- **保存案例：**支持“我的案例”的实验台可保存当前输入，并通过 JSON 导入或导出案例。案例文件不同于完整学习记录备份。

步骤解释、图形、操作计数和代码高亮用于一起理解算法：例如排序时，先看被比较的两个元素，再观察是否发生交换，最后核对比较次数。变量监视器显示当前值、上一步的值及变化；在递归、图和内存专题中还会出现与主题对应的状态视图。修改输入后应点击“应用数据”，让时间轴按新数据重新生成。

## 做题与复习

在[算法推演题库](https://rainandcr.github.io/DataStructure-Lab-codex-version/#/lab/practice)中，“学习练习”逐题提交并查看解析；“模拟测验”可设置题量和时间，交卷后统一看结果。可按章节、知识点、算法、难度和题型筛选。题目是站内原创示例，**不是官方真题**；408 标签也未经最新官方考纲核验。

[学习记录与复习](https://rainandcr.github.io/DataStructure-Lab-codex-version/#/lab/study)提供学习总览、错题本和复习计划。错题可重新作答、记录错误原因或加入复习。复习时可以评价掌握程度并调整下次日期。“已学习”是主动标记，与做题后的掌握状态不同。

### 学习练习

先选择“大学课程”或“考研 408”学习视角，再按章节、知识点、算法、难度和题型筛选。选择左侧题目并作答，点击“提交答案”查看标准答案与解析。可“再次练习”或进入“下一题”；题目下方的链接能返回对应动画或知识点。

### 模拟测验

切换到“模拟测验”，设置题量、限时和每题分值，点击“抽题开始”。提交整份试卷或倒计时结束后，页面统一显示得分、错题和解析。未提交的测验草稿会保存在当前浏览器；换地址或设备前仍应导出备份。

### 错题本和复习计划

在“学习记录与复习”中切换“错题本”，可按章节与知识点筛选，查看解析、写下错误原因，并选择“重新作答”“查看动画”或“加入复习”。在“复习计划”中可以调整间隔、重排日期；复习后按自己的理解选择“需要复习”“基本掌握”或“已掌握”。默认复习间隔为 1、3、7、14、30 天，可自行修改。仅打开页面或观看动画不会自动证明已掌握。

## 备份与换设备

网站没有账号或云同步。进度、作答和设置仅保存在**当前浏览器的当前网站地址**；清除网站数据、使用无痕模式或更换设备都可能使记录不可见。建议定期进入“学习记录与复习”，点击 **导出备份** 下载 JSON 文件。

从本地开发地址迁移到线上站点时，先在原地址导出，再在新地址点击 **合并导入**。数据不会自动跨地址转移。详细规则见[数据迁移说明](docs/DATA_MIGRATION.md)。

### 导出与导入的具体步骤

1. 在**旧地址、旧浏览器**打开“学习记录与复习”，点击“导出备份”，妥善保存下载的 `.json` 文件。
2. 在**新地址、新浏览器**打开同一页面，点击“合并导入”，选择刚下载的文件，确认页面提示“已合并导入”。
3. 检查学习总览、错题本、已学习标记和保存的案例。确认无误前不要删除原浏览器数据或备份文件。

完整备份包含学习、作答、主题偏好、已学习标记、保存的案例及未提交测验草稿。导入会合并兼容记录并对重复作答去重；格式不兼容时页面会拒绝覆盖原记录。备份文件可能包含个人学习记录，请自行保管。

## 常见问题

**打开网站后为什么没有之前的进度？** 本地地址、GitHub Pages 地址和不同浏览器各自保存一份数据。回到原地址导出，再到新地址“合并导入”。

**为什么改了输入，动画仍是旧数据？** 输入后需要点击“应用数据”。如果页面提示格式或范围错误，按当前实验台的提示修改。

**为什么某个知识点没有对应练习？** 题库是有限的站内原创示例，部分筛选组合没有题。可选择“练习本章题目”或在题库放宽章节、算法、题型筛选。

**代码能直接运行吗？** 不能。代码对照用于理解内置算法步骤，不是在线编译器。指针地址、断点和递归栈也都是教学模拟。

**手机能用吗？** 可以通过浏览器打开线上网址；复杂图形、代码和多栏对比在较宽屏幕上更容易观察。

## 本地运行（开发者）

主界面位于 [`web/`](web/README.md)，采用 React、TypeScript 和 Vite。需要 Node.js 22 或更高版本。在 `web/` 中执行：

```powershell
cd web
npm ci
npm run dev
```

打开终端显示的地址。网页测试与生产构建分别运行 `npm test`、`npm run build`；回到仓库根目录执行 `npm test` 可检查旧版算法。部署入口和 SPA 深链接配置见 [`web/README.md`](web/README.md)。

根目录保留早期原生 JavaScript 教学版，两套入口彼此独立。使用细节见[详细使用指南](docs/USER_GUIDE.md)；开发资料见[项目架构](docs/ARCHITECTURE.md)、[算法约定](docs/ALGORITHM_GUIDE.md)和[题库约定](docs/QUESTION_BANK_GUIDE.md)。
