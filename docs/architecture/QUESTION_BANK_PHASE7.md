# 阶段 7：交互式题库与算法推演

入口：`/lab/practice`。在阶段 6 知识点页可直接跳到对应练习；尚无该知识点题目时自动转到本章题目或题库首页。现有九章目录、算法 URL、步骤引擎和进度键不变。

## 首批范围

`web/src/data/questionBank.ts` 提供 22 道原创示例题，覆盖线性表、栈队列、树、查找与排序；包括单选、多选、判断、数值填空、复杂度和 6 道可点击的推演题。推演题分别为冒泡交换、栈出栈、队头队尾、二叉树前序、BFS 下一顶点、折半查找首次中点。树与图题在图形节点上选择。推演题的标准答案与标准状态由现有 `bubbleSort.generate` 或 `topicRun` 执行步骤复算并校验，图题在题干明确邻居入队次序。题目均标明“站内原创示例”；408 只是未核验的复习标签，不是官方真题。

`web/src/components/PracticeLab.tsx` 提供章节、知识点、算法、难度、题型和课程/408 视角筛选。学习练习提交后立即显示对错、解释、重练与动画入口。模拟测验可设置题量、分钟数、每题分值，随机无重复抽题；提交或时间结束后统一评分，逐题显示解析与未答/答错项。离开页面会清理计时任务；未提交的试卷不写入历史。

作答记录独立保存在 `datastruct-answers-v1`，格式为 `{version:1,records:[...]}`；每条记录含题目 ID、答案、对错、练习模式、时间与记录版本。最多保留最近 500 条。`web/src/data/questionAttempts.ts` 对读取格式做严格校验：损坏或未来版本不会被空记录覆写，写入失败会在页面提示；未知旧题 ID 保留，以便后续迁移。旧 `datastruct-theme`、`datastruct-completed` 均未改动。当前仅本机记录，不提供错题本、间隔复习或跨设备同步，这些属于下一阶段。

## 新增题目规范

1. 在 `questions` 中使用稳定唯一 ID，填写题型、题干、选项或输入、答案、中文解释、知识点 ID、算法 ID、难度、来源、版本。只写原创题或有明确授权的材料；不得把未经核验的题标为官方真题。
2. 多选答案保存为选项文本数组；数值题保存十进制答案字符串；判断题使用“正确/错误”。推演题还要写初始数据、标准状态、验证规则、步骤引用和错误提示。若算法允许多个合法次序，必须在题干限定顺序，或在验证器中接受等价序列。
3. 运行 `validateQuestionBank()`：拒绝重复 ID、缺内容、无效选项/映射、非法推演输入，以及答案或标准状态与实际算法步骤不一致。修改算法步骤时同步检查受影响的题。
4. 执行 `npm test`、`npm run build`，并在浏览器核对学习提交、模拟测验、刷新后历史及知识点/动画跳转。不要把题目数据写进旧进度键。

## 验证结果

`web/src/data/questionBank.test.ts` 覆盖题库校验、六种题型判分、数值等价、抽题及推演答案对照；`questionAttempts.test.ts` 覆盖版本、损坏格式和写入失败。浏览器手工核对了普通题、交换推演题、测验报告与刷新后的记录。网页测试 15 个文件、167 项通过；根目录旧版测试 11 项通过；网页 TypeScript 检查与生产构建通过。项目没有单独的 Lint 命令。
