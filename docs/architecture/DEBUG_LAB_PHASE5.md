# 阶段 5：代码调试与算法错误实验室

入口：`/lab/debug`，侧栏“代码调试与错误实验室”。页面是独立学习辅助区，不修改已有 44 个课程入口、旧算法步骤、路由或本地学习进度。

## 三项功能

1. **代码跟踪**：直接消费现有冒泡排序与折半查找的步骤、变量、数据快照和 C/C++ 行映射；复用 `VariableMonitor` 与 `useTimeline`。点击代码行可设置教学断点，播放在下一次到达该行时暂停；仍可手动单步、回退、拖动时间轴和调速。断点通过步骤的 `highlightedLines` 判定，不是原生 C/C++ 调试器。
2. **错误实验室**：`web/src/engine/debugLab.ts` 独立注册十个 `ErrorCase`，每项包含 `caseId`、`algorithmId`、标题、错误代码、输入、预期与错误行为、解释、错误检查点、标签、难度、模拟步骤、判断题和修复代码。单链表插入与折半查找边界错误均有逐步可回退状态；释放后访问及数组越界复用 `memorySimulator.ts` 的受控快照。其他案例覆盖栈、循环队列、冒泡、快排、DFS 与递归出口。未定义行为只展示预警，不实际执行。
3. **预测与边界测试**：在代码跟踪中，学员先预测下一步是比较、交换、访问还是其他操作，提交后才显示答案与步骤解释；答案来自下一步结构化 `operations`。冒泡边界测试调用现有解析器和步骤生成器，覆盖空输入、单元素、重复值、全相等、正序、逆序、合法极值、非法输入。

## 扩展案例规范

新增错误案例时，在 `errorCases` 注册稳定 `caseId`，提供同一输入下可重复的完整步骤快照和两种语言有效的代码行。`checkpoints` 指向实际错误行，修复说明须解释状态如何偏离预期。若已有安全模拟器覆盖该错误，使用 `memoryScenario` 复用其步骤；否则提供完整 `frames`。错误步骤严禁实际执行越界、释放后访问或无限递归。新增案例同时补充步骤序列化、代码行和最终错误状态测试。

## 验证与限制

`web/src/engine/debugLab.test.ts` 验证跟踪快照、十个错误案例、关键状态、预测事件与八组边界结果；`executionV2.test.ts` 验证断点停止和继续。2026-10-24 全量检查：新版 156 项测试、旧版 11 项测试及生产构建通过；浏览器验证了断点切换、折半查找案例答题与八组边界结果。案例中的错误代码为教学片段，外部数组、辅助函数和图邻接表由示例预置。项目仍不提供编辑、编译或运行任意用户 C/C++ 代码，也不保存作答记录。
