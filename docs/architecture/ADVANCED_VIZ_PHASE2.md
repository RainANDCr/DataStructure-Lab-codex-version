# 阶段 2：高级算法可视化实验室

本阶段直接扩展现有 SVG 实验台和步骤时间轴，没有替换算法引擎、路由或原有存储键。入口仍为 `/lab/:id` 与 `/lab/compare`，既有 44 个课程 id 不变。

## 交互与联动

- `web/src/components/TopicLab.tsx`：图节点可拖动或用方向键移动；图画布可拖动平移、缩放、重置视图和全屏。图快捷编辑保留原有无权边格式 `0-1`，增加 `0-1:4` 带权边；权重允许 0–99。邻接矩阵在带权图中显示权重，空位用 `·` 区分零权边。BFS 页面单独显示队列、已发现与已访问节点。
- `web/src/engine/topicCore.mjs`：BFS 每步复制 `queueIndices` 与 `discovered`，连同原有 `done` 和 `output` 一起进入步骤快照。回退、跳转和调速复用 V2 时间轴。带权信息只用于绘图和邻接存储，BFS/DFS 的访问顺序不按权重改变。
- `web/src/components/SortingLab.tsx`：堆排序的数组和完全二叉树读同一 `values` 快照，初始步骤也显示树；归并排序的原数组、当前左右子区间和临时数组读同一步状态，右边界按半开区间处理。
- `web/src/components/ComparisonLab.tsx`：保留原同步时间轴，增加独立播放和“插入 vs 归并”；每侧显示比较、写入、访问、可计操作、完成状态、理论复杂度与浏览器单次步骤生成耗时。小输入耗时易受调度影响，不把动画时长当作算法运行时长。计数仅汇总算法已有字段，不从中文说明推断事件。
- 第一批结构中的顺序表、单链表、二叉树和图提供随机样例及恢复默认数据；原有表操作、树约束与图边编辑继续由各自算法验证。图允许孤立节点和不连通分量；不允许空图、自环、重复或越界边、超限权重。

## 案例格式

`web/src/engine/labCases.ts` 使用 `{ "version": 1, "algorithmId": "graph", "input": "0, 1", "options": { "order": "bfs", "start": 0, "edges": "0-1:4" } }`，图案例可附加 `positions` 保存节点布局。导入限制 10 KB，检查字段、算法 id、选项和坐标，并用现有算法生成器验证结构后才载入。案例最多保留 20 条于新键 `datastruct-cases-v1`；导出为 JSON 文件。旧 `datastruct-theme` 和 `datastruct-completed` 不读取或改写；此前项目没有案例存储格式，因此没有需要迁移的旧案例。未知版本会被拒绝而非覆盖。当前实验台只载入同一算法的案例，避免跨课程替换页面状态。
