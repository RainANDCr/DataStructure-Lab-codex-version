# 阶段 6：课程知识体系与 408 复习图谱

## 范围与入口

新增 `/lab/knowledge`，沿用现有九章目录和 `/lab/:id` 动画入口。页面提供“大学课程”和“考研 408”两种视角、章节导学、可点击的先修关系图、跨章节学习路径和知识点详情。URL 的 `chapter`、`point`、`mode` 参数可直接定位内容；非法章节参数回到第 2 章。

`web/src/data/knowledge.ts` 保存 `ChapterGuide`、`KnowledgePoint` 和图谱关系；`web/src/components/KnowledgeLab.tsx` 呈现内容；`web/src/App.tsx` 在已有算法页添加反向知识入口。两边均复用现有算法路由，不改动算法引擎、播放器或学习进度格式。

## 内容基线

九章都有章节简介、目标、难点、前置知识、关联动画、练习建议和复习提示。第 2、3、6、9 章中，现有每个动画都有对应的完整知识点；每个完整知识点包含定义、示意关系、性质、例题推演、常见错误、动画入口和答案揭示式自测。其他五章保留概要节点并标明“建设中”，可沿图谱跳转到关联动画。自测当前只揭示答案，不判分、不存储作答记录。

教材章节与 408 复习标签分别保存在 `chapterId` 和 `examTags`。`syllabusMapping` 记录站内版本、来源与 `verified: false`；页面明确告知用户这些标签未经最新官方考纲核验，不展示考频或命题概率。`references` 指向站内教材目录和站内动画，不冒称外部教材引文。

## 兼容性与检查

- 原九章算法路由、导航、动画和本地进度保持原样；新增内容没有持久化字段，也不需要数据迁移。
- 先修关系、动画引用、知识点唯一性与循环依赖由 `web/src/data/knowledge.test.ts` 校验；四章内容测试会检查现有动画都有知识入口。
- 浏览器核对了九章导航、知识节点选择、答案显示、单链表与 Dijkstra 的知识页/动画双向跳转，以及 408 模式的未核验提示。
- `web` 全量 Vitest：13 个测试文件、160 项通过；`web` 生产构建（含 TypeScript 检查）通过；根目录旧版算法测试 11 项通过。项目目前没有单独的 Lint 命令。

下一阶段可以在现有 `KnowledgePoint` 上接入独立题目与作答记录；不得把未核验标签当作官方考纲，也无需替换旧算法页。
