# 用户数据基线与非破坏迁移方案

审计日期：2026-10-24。当前仅有浏览器同源 `localStorage`，无 IndexedDB、服务器数据库、账号或跨设备同步；本文件是将来升级设计，**本阶段未运行迁移**。

## 现有结构及风险

| 键 | 当前值（JSON） | 读取/写入 | 约束 |
| --- | --- | --- | --- |
| `datastruct-theme` | 字符串 `"light"` 或 `"dark"` | `web/src/lib/storage.ts` 的 `savedTheme`/`save`；`web/src/App.tsx` 的状态/effect | 未设置时默认浅色；非 `dark` 读成浅色 |
| `datastruct-completed` | 字符串 id 数组，例如 `["bubble","kmp"]` | `savedCompleted`/`save`；`App.tsx` 挂载及标记操作 | 只过滤非字符串；百分比按当前目录中可用 id 计算；未知字符串会保留在状态中 |

读取失败或值不是数组时，`savedCompleted` 返回 `[]`；组件挂载后 effect 无条件写回，可能将原始数据覆写为空数组。`save` 捕获写入异常但不通知用户。主题键有类似的默认回写行为。未来**不能直接把版本化对象写入这两个旧键**。`localStorage` 按 origin 隔离：localhost 端口变化、正式域名变化都不会自动带走数据。

## 目标格式与版本号

保持两个旧键及其原有 JSON 形状。新数据用独立 `datastruct-v2` 键：

```json
{
  "schemaVersion": 2,
  "completedLessonIds": ["bubble", "kmp"],
  "theme": "dark",
  "updatedAt": "2026-10-24T00:00:00.000Z"
}
```

这是建议的**最小示例结构**，不是当前已写入数据。以后题目、错题、学习路径等若需要持久化，按明确字段/独立键增量加到后续版本，先确定数据上限与私密性，再决定是否需要 IndexedDB 或服务端。版本号应是显式整数，迁移函数按 `v1 → v2 → v3` 逐级、可重复运行；禁止“看见对象就猜是新版”。

## 迁移顺序

1. 在任何 React 自动保存之前读取**原始字符串**和键是否存在，解析并验证旧字段。未知/损坏格式记录为“需要人工恢复”，保留原始值；不要落回默认值后写回。
2. 对合法旧数据做纯函数转换：复制已有 id，必要时去重但不丢弃未知字符串 id；保留合法主题。产生新对象时附版本号与时间戳。函数运行两次结果应一致，已有 `datastruct-v2` 的有效数据不得被旧键覆盖。
3. 写入新键后立即读回、解析、校验条目和版本号；成功才把新版设为当前读取源。写失败、容量不足或私密模式禁用时维持旧版可用，并在界面明确提示本次修改未保存。
4. 在过渡期旧页面仍可读取旧键；仅对旧版能表达的 `theme` 与 `completed` 值保持兼容写入。不能把练习记录压成旧格式。旧键不得删除、改名或转成对象。
5. 迁移、旧键兼容写入和用户可见保存状态都经测试后，才考虑开启新版功能。多标签页需监听 `storage` 事件或采用冲突策略，避免较旧标签页覆盖新数据。

## 验证矩阵

至少测试：键缺失；合法空/非空进度；包含未来未知课程 id；错误 JSON；非数组进度；合法 `datastruct-v2`；比当前代码更新的版本号；被禁用/写入失败的 `localStorage`；重复执行迁移；两标签页并发修改。对错误 JSON 和未知版本，必须断言原始字符串保持不变。现有测试尚无这些覆盖。

## 回退与跨域

回退到旧版应用时，它仍使用两个旧键，因此新版不得删除或改变它们。若新格式故障，停止读取/写入新键并回退旧版 UI，保留 `datastruct-v2` 供修复；绝不清空用户存储。站点换域或从本地端口迁移时，浏览器不会自动共享本地数据，后续应提供用户主动触发的导出/导入，验证文件格式后才写入；未经用户操作不声称已跨设备同步。

## 阶段 7 增量：作答记录

题库使用独立的 `datastruct-answers-v1`，结构为 `{ "version": 1, "records": [...] }`，与上文建议的 `datastruct-v2` 进度方案互不覆盖。读取到损坏或未来版本时，题库不写回默认值并提示保存不可用；未知题目 ID 的旧记录保留。浏览器本地只保存最近 500 次作答，版本升级应先复制、校验、再写入新键，不做破坏性迁移。当前不迁移或改写旧主题与已学习键。

## 阶段 8 增量：学习资料与复习

阶段 0 记录的旧键挂载自动回写风险，已在 `web/src/App.tsx` 修正为仅由用户切换主题/标记学习时写入；没有修改旧键格式。新增 `datastruct-study-v1` 版本对象，保存浏览、动画访问、掌握评价、复习和活动时间；沿用 `datastruct-answers-v1` 推导错题，不复制旧作答。用户主动导入兼容阶段 7 作答文件及阶段 8 完整文件，格式错误、未来版本、存储失败不会被默认空记录覆盖。详细范围见 [阶段 8 说明](STUDY_PROGRESS_PHASE8.md)。原文的 `datastruct-v2` 是未来建议结构，本阶段没有创建该键或破坏性迁移。

## 阶段 9 核对

`web/src/lib/storage.ts` 在显式保存旧主题/已学习值之前校验原始键；损坏或未知格式保留原文并向页面报告。上文建议的 `datastruct-v2` 统一存储结构依然**没有实施**。`web/src/data/studyProgress.ts` 现提供版本 2 的导出文件，包含作答、复习、主题、已学习标记、案例及测验草稿；导入会校验并尝试跨键回退。浏览器存储仍没有真正的跨键事务；实际备份和回退步骤见 [数据迁移说明](../DATA_MIGRATION.md)。
