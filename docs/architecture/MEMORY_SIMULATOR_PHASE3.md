# 阶段 3：指针与内存可视化模拟器

入口是 `/lab/memory`，位于侧边栏“指针与内存模拟”。它是独立教学实验台，不改变原 44 个课程 id、`/lab/:id` 的已有入口、旧算法生成器、播放器或浏览器存储。此模块不编译或执行任意 C/C++ 代码；`S:…`、`H:…` 均为确定性的教学模拟地址，不对应设备真实内存。

## 模型与步骤

`web/src/engine/memorySimulator.ts` 定义 `MemoryObject`（稳定 id、地址、栈/堆区域、类型、值、所有栈帧、分配与释放状态、节点链接）、`StackFrame`、`PointerReference`、`MemorySnapshot` 和 `MemoryMachine`。栈变量与堆节点分别按区域保存；引用关系由当前指针变量及堆节点字段构成，指向已释放对象时标记悬空。`head` 所能到达的链表由当前 `next` 链接计算，因此修改指针时链表图、堆卡片与引用图区消费同一个快照。

`generateMemorySteps` 为每个受控案例生成完整、可序列化的 V2 `ExecutionStep`。每步复制栈、堆、引用、警告与可达链表状态，记录结构化操作事件、中文说明和 C/C++ 行号。`MemoryLab.tsx` 直接复用 `useTimeline`，支持播放、暂停、前后步、任意跳转、调速和重置。回退只读取该索引的旧快照，不逆向执行副作用。

`MemoryMachine` 拒绝重复释放、释放栈变量、写入已释放对象及把节点链接到已释放对象。错误案例只在模拟状态添加警告，不执行空指针解引用、释放后读写或越界读写。释放后的字段在 UI 中显示“不可访问”。

## 教学案例

- 变量与指针：`a=10`、`p=&a`、`*p=20`。
- 动态节点：分配、写入、释放、清空指针。
- 单链表中间插入与删除：展示分配/定位、`next` 修改、释放、短暂悬空及清空局部指针。双链表插入额外展示 `prev` 更新顺序。
- 常见错误：空指针解引用、悬空指针、释放后访问、内存泄漏、链表断链、引用覆盖、数组越界。代码片段中的 `make_list` 等教学辅助函数未展开，不能直接作为独立程序编译。

## 验证与边界

`memorySimulator.test.ts` 检查所有案例的行号、序列化，单/双链表最终连通性，释放状态和悬空引用，栈地址、快照回退、重复释放保护及错误提示。浏览器已检查 `/lab/memory` 的深链接、插入逐步播放和删除中间帧。页面没有新增账号、后端、数据库或旧键迁移。

2026-10-24 实际检查：`web/` 的测试 140/140、`npm run build`（含 `tsc -b`）通过；根目录旧版测试 11/11 通过。浏览器另外检查了空指针错误案例的警告展示。

当前模拟器仅覆盖内置案例，使用固定的小规模对象与一个 `main()` 栈帧；它不模拟真实 ABI、分配器复用、地址随机化、完整 C/C++ 对象生命周期或任意源代码。这些边界在页面中明确标为教学模拟。
