# 2.0 兼容性保护计划

本文件是后续实施约束，不代表本阶段已经创建分支、改造引擎或新增功能。审计发现当前工作目录**没有 `.git`**，因此无法运行有效的 `git status`、判断未提交改动或创建分支；不得将其描述为“干净工作区”。本阶段只新增五份要求的文档，所有原有文件原样保护。

## 开工门槛与隔离

1. 先确认此目录来源及完整版本控制元数据。若无法恢复原仓库，在写入 Git 元数据之前先将当前目录做完整、可校验的异地备份；保留用户现有文件、配置与浏览器数据，不执行 `reset`、`clean`、强制检出或覆盖。
2. 恢复/建立 Git 后先检查实际 `git status --short`。将所有已有内容记录为稳定基线或明确归属，不把用户改动混入新功能提交。根据真实默认分支及状态创建独立 `feature/2.0-foundation` 分支；名称可调整，**不能假定分支已存在**。
3. 在该分支记录基线：根目录 `npm test`；`web/` 的 `npm ci`、`npm test`、`npm run build`。当前没有 Lint 脚本，不能把它列成通过项。CI 使用 Node 22，本机检查为 Node 24；合并前须在 CI 环境复测。
4. 任何阶段失败时先停止新功能合并，保留现场和数据快照；仅回退该阶段新增代码/开关，避免触碰旧存储键与既有稳定入口。

## 兼容合同

| 对外/对内合同 | 当前事实 | 后续要求 |
| --- | --- | --- |
| URL 与导航 | `/` 跳转 `/lab/bubble`，`/lab/:id` 由 `catalog.ts` 查找，`compare` 为 `/lab/compare` 特例 | 保留所有现有 id、深链接及未知路径回退；新课程采用新 id，不复用旧 id；持续保留 Vercel/Netlify SPA 回退 |
| 算法步骤 | `AlgorithmStep<TState>` 的快照、高亮元素、分语言行号、变量、时长 | 新可视化以适配器输出该合同；允许添加可选字段，不改既有字段语义或现有生成器返回值 |
| 播放器 | `TopicLab`、`SortingLab` 各自控制步骤/定时器；对比页共用序号 | 优先创建新组件消费现有步骤，而非替换旧播放器；新低层视图在功能开关下接入 |
| 教学代码 | C/C++/Python 的只读代码行与 tag 映射 | 旧片段和行映射继续可用；可执行代码走独立来源/验证适配器，避免伪称旧片段可编译 |
| 用户数据 | `datastruct-theme`、`datastruct-completed` 两个 `localStorage` 键 | 不改变旧键现有结构；新增版本键、非破坏迁移、失败回退，见 [数据迁移方案](DATA_MIGRATION_PLAN.md) |
| 旧版入口 | 根目录 `index.html` + `server.mjs` 可独立运行 | 保留原入口和静态资源；若以后退役，先提供等价跳转与数据迁移验证 |
| 依赖/API | 目前无业务后端 API；依赖由 `web/package-lock.json` 固定 | 新接口使用新增路径/可选参数；无关依赖不升级、不重写锁文件；引入后端前先定义兼容合同 |

## 增量扩展落点

下列目录是**建议**，目前均未创建，不应误读为现有功能：

```text
web/src/features/advanced-viz/    # 新的高级算法轨迹与视图
web/src/features/cpp-runtime/     # C/C++ 编译/执行/内存模型适配层
web/src/features/study-408/       # 大纲、学习路径、练习与错题
web/src/compat/                   # 旧步骤/代码/URL 的适配器与合同测试
web/src/data/migrations/          # 版本化浏览器数据迁移
```

优先复用 `engine/types.ts`、`TopicLab`/`SortingLab` 的现有播放交互、`graphEditing.ts`、`catalog.ts` 的课程元数据、`StudyNotes`。新主题先作为独立模块注册，再接导航；新能力用默认关闭的功能开关逐段发布。不要未经验证就替换 `topics.ts`、`topicCore.mjs`、`App.tsx` 的路由或状态管理。对高风险的 C/C++ 运行时，先独立验证生成轨迹与真实执行的一致性，再映射到页面。

## 最小兼容回归门禁

每阶段维持根目录 11 项和 `web/` 108 项当前测试、`tsc -b` 与生产构建。新增测试只针对变化的关键合同：已保存进度能读取、异常存储不被覆写、旧 URL 仍可直达、已有主题默认输入仍生成步骤和三语言高亮、功能开关关闭时旧页面不变。需在浏览器中至少抽查深链接、播放/暂停、主题与进度刷新；目前没有自动化浏览器端测试，计划中不能声称已覆盖。

## 安全回退

发布前保留旧版可部署静态产物和存储原值的可恢复副本。新模块异常时先关开关并恢复上一版静态资源，保留新旧数据键，绝不通过清空浏览器存储或删除数据库来回退。若未来新增数据库，只使用向后兼容的新增表/字段与可重复迁移；旧字段删除须等所有消费者切换、备份验证及单独批准后另行实施。当前没有数据库，故本阶段没有数据库迁移操作。
