# 阶段 4：递归调用栈与函数执行可视化

入口：`/lab/recursion`，侧栏“递归调用栈”。此页是独立教学辅助实验台，不修改课程目录数量、旧版树遍历、排序和图模块。

## 实现

- `web/src/engine/recursion.ts`：从确定性输入生成 `ExecutionStep<RecursionState>`。每步包含完整且可序列化的数组、输出、调用树、活动栈帧、高亮、C/C++ 代码行和事件。调用树保留已返回节点，栈仅保留未弹出的帧；`RETURN` 记录结果，`FRAME_POP` 移除帧并激活父函数。
- `web/src/components/RecursionLab.tsx`：复用现有 `useTimeline`，可播放、暂停、单步、回退、跳转、调速、重置与切换输入。页面同步展示算法结构、调用树、栈帧、返回值和代码。离开页面时播放器的清理逻辑不变。
- 首批示例：阶乘、二叉树前/中/后序、快速排序、归并排序、递归 DFS。C 与 C++ 选项对应同一段兼容两种语言的核心伪完整教学代码；数组、`visit`、`merge` 和邻接表由示例预置，不声称运行用户代码。
- 调用事件：`CALL`、`PARAM_BIND`、`LOCAL_UPDATE`、`RECURSE`、`RETURN`、`FRAME_POP`；另有 `VISIT`、`COMPARE`、`SWAP`、`WRITE`、`READY`、`DONE`。页面依据结构化事件和状态渲染，不从中文说明推断操作。

## 边界与兼容

阶乘限制为 0–8，二叉树最多 15 个层序节点，排序和 DFS 最多 8 个值，递归深度最多 18 层，步骤最多 600。输入整数须在 -99 到 99 之间，DFS 节点值须唯一。当前示例均为线性调用数量；如增加指数级递归算法，应在生成前估算调用数量并给出明确预警。

该实验台复用已有 V2 步骤协议与时间轴；旧模块、旧 URL 和本地学习进度存储格式均未改动。快排和归并等原课程页面仍按原机制播放。无需数据迁移。回退只切换预生成快照，不会重新运行算法。
