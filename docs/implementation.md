# 见序：数据结构实验室

> 本文记录根目录原生旧版。React 新版的执行引擎增量升级见 [算法执行引擎 V2](architecture/EXECUTION_ENGINE_V2.md)。

用户确认：用于自学，动画逐步对应 C、C++、Python 代码。当前包含顺序表、单链表、栈、队列、朴素模式匹配、二叉树遍历、图的遍历、二分查找、冒泡排序、快速排序。教材仅提供目录，不声称复现正文。

## 实现
- 原生 HTML/CSS/ES modules，无运行时依赖，本地 Node 静态服务。
- algorithms.mjs：纯算法生成不可变步骤，包含数组、活动元素、完成元素、变量、代码语义标签、中文解释。三种代码通过语义标签映射行号。
- lessons.mjs：课程元数据与三语言教学片段；app.mjs：选择课程、参数校验、播放和 SVG/DOM 展示；style.css：响应式样式。
- 输入限制为最多 16 个 -99 至 99 的整数，树最多 15 个节点，图最多 10 个不重复节点；二分查找要求有序；线性结构支持空输入。代码为核心教学片段，不是在线编译器。
- 浅蓝灰底色 #f3f6fa、深蓝文字 #182c43、青绿强调 #087f72、橙色比较 #c06b18、白色工作面。桌面章节/动画/代码三栏，小屏按阅读顺序堆叠。

## 验收
- 测试排序结果、重复值、负值、空数组；查找成功失败；插删边界；栈队列下溢；三种树遍历；快照不受后续修改影响。
- 检查每个步骤都能映射到三语言的代码行。
- 浏览器检查切换主题与语言、播放暂停、单步回退、输入错误和窄屏布局。
- 无账号、后端数据库、在线编译、题库；未实现章节明确显示规划状态。
