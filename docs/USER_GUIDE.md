# 使用指南

1. 在左侧九章目录选算法，或进入“课程知识体系 · 408”按章节与先修关系学习。章节标“建设中”的知识页提供概要，不代表完整教材章节。
2. 在算法页输入数据并应用，使用播放、暂停、前后步、进度滑块和速度选择器观察状态；代码标签可切换 C、C++、Python。当前高亮行、变量和图形对应同一步。某些专题还提供图编辑、内存模拟或递归视图。
3. 从知识点打开关联动画，再进入“算法推演题库”。学习练习即时给出解析；模拟测验在提交或倒计时结束后统一判分。题库共有 22 道站内原创示例题，408 视角不是官方真题。
4. 错题会进入“学习记录与复习”。可补充错误原因、重做、看动画、安排或调整复习日期；评价复习后更新掌握状态。仅浏览或观看动画不等于掌握。默认复习间隔 1、3、7、14、30 天可修改，属于提醒方式而非普遍学习定律。

“已学习”是用户主动标记的算法进度；知识点掌握状态依据作答与主动评价；学习活动时间只累计页面可见、窗口聚焦且最近 60 秒有交互的完整 15 秒区间。三者含义不同。

数据只保存在当前浏览器的当前地址。浏览器隐私模式、清理站点数据、换端口或换域名都可能让原记录不可见。学习记录页的“导出备份”现包含作答、复习、已学习标记、主题偏好、保存的算法案例及未提交测验草稿；换地址前先下载文件，再在新地址“合并导入”。按 [数据迁移说明](DATA_MIGRATION.md) 核对；格式不兼容时页面会拒绝覆盖。删除个人错题前会再次确认。没有账号、云同步或任意用户代码执行。
