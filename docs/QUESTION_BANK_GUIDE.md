# 题库维护指南

题目定义于 `web/src/data/questionBank.ts`，现有 22 道站内原创示例题，其中 6 道可视化推演。题目包含稳定 ID、类型、题干/选项、标准答案与中文解释、知识点和算法 ID、难度、来源及版本。`PracticeLab.tsx` 提供学习练习和限时测验，`gradeAnswer` 负责判分；推演题还需与实际算法步骤及标准状态核对。408 标签只是站内复习分类，未核对最新官方考纲，不得称为官方真题。

新增题目时先确定唯一且不会复用的 ID，并检查知识点/算法链接确实存在。多选应明确是否需要全部选对；数值题应核验可接受表示；图或排序推演要在题干限定访问/比较顺序，或在判分器中明确允许等价答案。解析应解释为何正确及容易误解的边界。题库变更后运行 `validateQuestionBank()` 相关测试和网页完整测试，再检查练习与知识点深链接。

作答以 `{version:1,records:[...]}` 存入 `datastruct-answers-v1`，最多保留最近 500 条。错题本从作答记录推导；旧题下架后仍保留原 ID 和历史，但无法再展示已删除题干。新版本题目不应把旧 ID 重新分配给不同问题。`datastruct-study-v1` 单独保存错误原因、复习与掌握评价。导出/导入范围与限制见 [`DATA_MIGRATION.md`](DATA_MIGRATION.md)。
